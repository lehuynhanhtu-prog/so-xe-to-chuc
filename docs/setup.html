Sổ Xe Tổ Chức 4.8.2

Mở ứng dụng · Tải ứng dụng

Mỗi tổ chức dùng hai tài khoản Google khác nhau: một tài khoản lưu dữ liệu Admin và một tài khoản lưu dữ liệu NSD.

Thiết lập Google

  1. Bật Google Drive API và Google Picker API trong Google Cloud.
  2. OAuth Web Client: thêm origin https://lehuynhanhtu-prog.github.io.
  3. API key: giới hạn website https://lehuynhanhtu-prog.github.io/* và Google Picker API.
  4. Nếu OAuth ở chế độ Testing, thêm email Admin và NSD vào Test users.
  5. APK Android cần OAuth Client loại Android, package vn.soxe.organization và SHA-1 trong hướng dẫn Android.

Quyền tài khoản

  • Admin / Admin bổ sung: toàn quyền xem, sửa, xóa, phân công và bàn giao.
  • Admin xem: xem và xuất dữ liệu; không sửa, xóa, phân công hoặc bàn giao.
  • NSD: chỉ xem lịch sử giao dịch do chính mình nhập. Chỉ khi đang quản lý xe, NSD mới được nhận cảnh báo và thêm/sửa/xóa giao dịch của mình hoặc bàn giao xe. Sau bàn giao, các quyền này tự khóa; phân công lại sẽ tự khôi phục.

Đăng nhập và dữ liệu

Admin kết nối Google lưu dữ liệu Admin rồi Google lưu dữ liệu NSD; hai tài khoản phải khác nhau. NSD kết nối đúng Google lưu dữ liệu NSD, sau đó đăng nhập bằng tên và mật khẩu riêng; lần đầu phải đổi mật khẩu. Dữ liệu được mã hóa trước khi lưu trên Drive; ứng dụng không lưu mật khẩu Google.
