Sổ Xe Tổ Chức 3.1

Mở ứng dụng

Tải bộ web 3.1

Cấu hình chung với Sổ Xe cá nhân

  1. Mở Google Cloud Console, chọn dự án có số 862228353042.
  2. Trong APIs & Services → Library, bật Google Drive API, Google Picker API và Gmail API. Trong Google Auth Platform → Data Access, thêm https://www.googleapis.com/auth/gmail.send và https://www.googleapis.com/auth/gmail.readonly. Gmail send là quyền nhạy cảm, Gmail readonly là quyền hạn chế; ứng dụng dùng rộng rãi có thể cần Google xác minh. Nếu đang Testing, thêm tất cả người dùng vào Test users.
  3. Trong Credentials, sửa OAuth Client ID loại Web đang dùng. Thêm Authorized JavaScript origin: https://lehuynhanhtu-prog.github.io. Không nhập đường dẫn /so-xe-to-chuc vào origin. Giữ origin Sổ Xe cá nhân.
  4. Tạo hoặc dùng API key của cùng dự án. Giới hạn Website referrers: https://lehuynhanhtu-prog.github.io/* và https://docs.google.com/*; API restrictions: Google Picker API và Google Drive API. Không dùng Client Secret.
  5. Trong ứng dụng → Cấu hình Google, dán Picker API key. Client ID và Project number đã điền sẵn. Admin vẫn có thể đăng nhập và tạo tổ chức trước khi có key.
  6. Nếu OAuth còn ở Testing, thêm email của Admin và NSD vào Test users. Mỗi người dùng tài khoản Google riêng.

Admin khởi tạo

  1. Đăng nhập Google, chọn Tạo tổ chức mới, đặt mật khẩu mã hóa riêng (ít nhất 6 ký tự). Mật khẩu không phải mật khẩu Google.
  2. Tạo NSD bằng đúng email Google, tên định danh và vai trò. Email điền sẵn @gmail.com; nhập phần tên hoặc thay bằng email Google đầy đủ. Đặt mật khẩu mở lời mời và cấp quyền gửi Gmail; app tự gửi email chứa JSON mã hóa.
  3. Chỉ gửi mật khẩu mở lời mời cho NSD qua kênh riêng; không gửi mật khẩu trong cùng email. Tiêu đề email thống nhất: [SOXE_TOCHUC][LOI_MOI][V3] <mã tổ chức>. Cấu hình Google công khai được kèm trong file mã hóa; không có OAuth token hay Client Secret.
  4. Thêm xe, phân công hoặc thay đổi/bỏ phân công.

NSD khởi tạo và kết nối

  1. NSD chọn “NSD: nhận lời mời qua email”, đăng nhập đúng Google và cấp quyền đọc Gmail. App tìm email lời mời; chọn lời mời, nhập mật khẩu Admin gửi riêng và đặt mật khẩu riêng. Không cần tải hay nhập file. File dự phòng vẫn được hỗ trợ nếu Gmail lỗi.
  2. Trong Google Picker, chọn đúng file ID app yêu cầu. File có trong mục Được chia sẻ với tôi.
  3. NSD gửi link nhật ký hiển thị ở Tổng quan cho Admin. App đã chia sẻ nhật ký với các Admin.
  4. Admin → Người sử dụng → Kết nối nhật ký, chọn file NSD gửi trong Picker. Đây là bước một lần cần thiết cho quyền drive.file.
  5. Admin bổ sung mở file tổ chức bằng lời mời và chọn từng file được xem của NSD qua nút Kết nối file được xem; cũng chọn từng nhật ký.

Thư mục dữ liệu

App tự tạo “Sổ xe tổ chức” trên Drive Admin và “NSD-Sổ xe tổ chức” trên Drive người quản lý/lái xe hoặc Admin chỉ xem. File tài khoản, tổ chức, bản dữ liệu và nhật ký được lưu bằng JSON mã hóa trong thư mục tương ứng. Các file cũ thuộc chính tài khoản sẽ được chuyển vào thư mục khi mở tài khoản; file được chia sẻ thuộc người khác không bị chuyển. App chia sẻ từng file, không chia sẻ toàn bộ thư mục.

Lưu và đồng bộ

NSD lưu giao dịch trên nhật ký mã hóa thuộc Drive của mình. Admin đồng bộ để tiếp nhận và phát bản dữ liệu được xem. Đồng bộ khi đăng nhập, bấm Tải lại hoặc mỗi 60 giây khi trang đang mở. Không có máy chủ chạy nền: Admin cần mở app để phát giao dịch mới cho các NSD khác. Thao tác chờ và thao tác bị từ chối được báo trong app.

Lái xe thấy giao dịch do mình nhập và giao dịch của xe đang được phân công; chỉ sửa/xóa giao dịch mình nhập. Vai trò chỉ xem không ghi dữ liệu. Admin có quyền đầy đủ. Gmail API chỉ dùng gửi/đọc lời mời mã hóa, không dùng đồng bộ giao dịch. Không dùng Apps Script hoặc thư mục công khai.

Mật khẩu, sao lưu và xóa

Đổi mật khẩu chỉ mã hóa lại file tài khoản riêng; không thay khóa dữ liệu tổ chức. App không lưu mật khẩu, OAuth token hoặc tên NSD trên thiết bị. Cấu hình Google công khai được lưu trên thiết bị. Quên mật khẩu riêng hiện chưa có quy trình khôi phục tự động; giữ mật khẩu và bản sao an toàn.

Sao lưu mã hóa cần mật khẩu riêng cho bản sao. Bản phát hành này tải bản sao, chưa cung cấp giao diện nhập phục hồi. Xóa tổ chức cần nhập tên và mật khẩu của Admin sở hữu; các file riêng thuộc Drive NSD vẫn thuộc NSD. Hãy chuyển chúng vào thùng rác trên tài khoản tương ứng nếu cần xóa vật lý.

Bản cũ Apps Script không tự chuyển dữ liệu sang mô hình mới. Giữ bản sao cũ trước khi chuyển; không xóa tổ chức cũ để thử bản mới.
