Tải Sổ Xe Tổ Chức · 4.7.0

Các phiên bản dùng chung chức năng và dữ liệu Google Drive. Cần Internet để đăng nhập, đọc và lưu dữ liệu.

Android

APK cho Android 7 trở lên. Giao diện tối ưu cho điện thoại; đăng nhập bằng mật khẩu hoặc sinh trắc học trên thiết bị hỗ trợ. Mở ứng dụng trong trình duyệt hệ thống, dùng phiên Google của trình duyệt.

Tải Android APK
  1. Tải và mở APK.
  2. Cho phép cài từ trình duyệt khi Android yêu cầu.
  3. Đăng nhập bằng mật khẩu → Tài khoản → Vân tay để bật đăng nhập sinh trắc học. Nếu muốn toàn màn hình, chọn Thêm vào màn hình chính trong Chrome.

Windows Portable

Windows 10/11. Không cần cài đặt hoặc quyền Administrator.

Tải Windows ZIP
  1. Giải nén ZIP.
  2. Chạy SoXeLauncher.exe hoặc Chay-So-Xe.bat.
  3. Ứng dụng mở trong trình duyệt mặc định; không cần cấu hình OAuth localhost.

iPhone / iPad

Ứng dụng web trên màn hình chính, giống cách cài Sổ Xe cá nhân.

Tải hồ sơ iOS
  1. Mở trang này bằng Safari và tải hồ sơ.
  2. Vào Cài đặt → Đã tải về hồ sơ → Cài đặt.
  3. Mở biểu tượng Sổ Xe Tổ Chức.
Hoặc mở Web trong Safari → Chia sẻ → Thêm vào Màn hình chính. Đây là Web App, không phải IPA/App Store.

Web

Dùng trực tiếp trong Chrome, Edge hoặc Safari. Luôn nhận bản cập nhật mới.

Mở bản Web

Tải gói Web 4.7.0 (ZIP)

Gói ZIP dành cho tự host HTTPS; cần cấu hình origin OAuth tương ứng.
Bản phát hành và mã kiểm tra SHA-256 · Hướng dẫn kết nối Google
